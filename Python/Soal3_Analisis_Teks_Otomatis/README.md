# Penjelasan Singkat Program

## 1. main.py
File utama program yang berfungsi untuk:
- Menjalankan analisis teks
- Menampilkan hasil analisis
- Menyimpan laporan ke file report.txt

---

## 2. analyzer.py
Berisi seluruh logic analisis teks seperti:
- Membaca file txt
- Menghitung jumlah baris
- Menghitung jumlah kata
- Menghitung huruf vokal dan konsonan
- Menghitung frekuensi kata
- Membuat grafik ASCII

---

## 3. utils.py
Berisi fungsi tambahan seperti:
- Menampilkan laporan ke terminal
- Menyimpan laporan ke file report.txt

---

## 4. input.txt
File input teks yang akan dianalisis program.

---

## 5. report.txt
File output hasil laporan analisis teks.
